# Pomodoro Timer Python Application
A simple light weight python program that uses the pomodoro system to help focus on tasks

## Installing 
> All module used in the project are pre-installed with python 
### Modules used 
    1. time 
    2. math 
    3. PIL
    4. tkinter

## Usage 
```
git clone https://github.com/ismsyd/pomodoro_timer_project.git
cd path/to/repo
python main.py
```
